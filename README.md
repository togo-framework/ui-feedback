# @togo-framework/ui-feedback

Feedback reporter surface (launcher, widget, hub) and issue manager board/drawer,
split out of `@togo-framework/ui`. Requires `@togo-framework/ui-core`.

```bash
npm install @togo-framework/ui-core @togo-framework/ui-feedback
```

```tsx
import { FeedbackButton, FeedbackHub, IssueBoard, IssueDrawer } from "@togo-framework/ui-feedback";
```
